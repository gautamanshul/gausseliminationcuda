## Implementation Notes

P1 changes only the physical thread mapping for the V6 panel update. The
logical update is unchanged:

`A(row, col) -= L(row, k) * U(k, col)`

Because V6 stores the working matrix in column-major order for cuBLAS
interoperability, adjacent rows in a fixed column are adjacent in memory. The
new mapping assigns `threadIdx.x` to rows and `threadIdx.y` to panel columns,
so neighboring lanes access neighboring addresses.

P2 replaces `solve_lu_col_major_v6_kernel<<<1,1>>>` with:

- `cublasStrsv(... LOWER, NON_TRANSPOSE, UNIT_DIAG ...)` for `L y = b`
- `cublasStrsv(... UPPER, NON_TRANSPOSE, NON_UNIT_DIAG ...)` for `U x = y`

This removes the previous serial CUDA-thread triangular solve from the timed
V6 path and uses the same vendor library family already used for V6 `STRSM`
and `SGEMM`.

rather than the already-fixed final triangular solve.
